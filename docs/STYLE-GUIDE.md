# SIF Studio 视觉设计指南
## Industrial Drafting Style Guide v1.0

> 适用范围：SIF Studio 全部前端界面（Vue 3 + Pinia）。
> 风格基调：**工业图纸**（P&ID / 工程制图）。
> 简洁、硬朗、线条犀利，等宽罗马字，零阴影、零渐变、零模糊。

---

## 1. 标准基础

| 标准 | 范围 | 本项目采用 |
|---|---|---|
| **ANSI/ISA 5.1-2024** | P&ID 仪表符号、识别、连线、颜色编码 | 5 色语义、Tag bubble、信号线 |
| **ISO 3098 / GB/T 14691-1993** | 技术制图字体（gothic 无衬线 / 罗马字） | 西文罗马字栈、中文仿宋体栈 |
| **ISO 7200** | 标题栏 8 必备字段 | 主框架顶栏（页眉） |
| **GB/T 18135-2008** | 电气工程 CAD 制图规则 | 线宽序列、字符宽高比、行距、字高序列 |
| **ISO 128 / GB/T 17453** | 视图与画法 | 网格、对齐 |
| **ISO 5457** | 图纸幅面 A0-A4 | 项目详情中的图幅标识 |

**关键事实**：ISO 3098 / GB/T 14691-1993 字体笔划与字高之比 = **1:14 或 1:10**；字符宽高比 ≈ **0.7**；
行距 ≥ **1.5 倍字高**；常用字高序列（mm）：**2.5 / 3.5 / 5 / 7 / 10 / 14 / 20**。

### 2.3 字族

```css
--font-mono:  "Consolas", "MONOTXT", "Courier New", monospace;
--font-roman: "ISOCPEUR", "Arial Narrow", Arial, Helvetica, sans-serif;
--font-cn:    "FangSong_GB2312", "FangSong", "STFangsong", "仿宋",
              "Microsoft YaHei", "PingFang SC", sans-serif;
--font-title: "Arial Black", "黑体", "SimHei", "Microsoft YaHei", sans-serif;
```

**使用规则：**
| 用途 | 字族 | 字重 |
|---|---|---|
| 页面标题 / 区段标题 | `--font-title` | 700 |
| 表头 / Tag / 按钮 | `--font-roman` | 600 |
| 正文 | `--font-roman`（西）/ `--font-cn`（中）| 400 |
| 位号 / 编号 / ID / 数字 / 命令 / 路径 | `--font-mono` | 500 |

### 2.4 字高与行高（等效于 ISO 3098 / GB/T 14691 序列）

| Token | px | 等效 mm | 用途 |
|---|---|---|---|
| `--fs-micro` | 11 | ≈ 2.5 | 表头、Tag |
| `--fs-xs`    | 12 | ≈ 3.5 | 辅助文本 |
| `--fs-sm`    | 13 | ≈ 5 | 正文 |
| `--fs-md`    | 15 | ≈ 7 | 区段标题 |
| `--fs-lg`    | 18 | ≈ 7 | 卡片标题 |
| `--fs-xl`    | 22 | ≈ 10 | 页面标题 |
| `--fs-huge`  | 32 | ≈ 14 | 数字（大统计）|

行距：`--lh-tight: 1.2`，`--lh-normal: 1.5`（GB/T 18135 最低要求），`--lh-loose: 1.8`。

### 2.5 线宽（GB/T 18135 线宽序列 0.18/0.25/0.35/0.5/0.7/1.0/1.4/2.0 mm，按 96 dpi ≈ 0.265 mm/px 折算）

| Token | px | 用途 |
|---|---|---|
| `--rule-hair` | 0.5 | 网格背景、表内细线 |
| `--rule-fine` | 1 | 输入框边框、表格行线 |
| `--rule-mid`  | 1.5 | 卡片边框、按钮边框、分隔线 |
| `--rule-bold` | 2 | 页面边框、标题栏边线、对话框边框 |

**线宽比 ≥ 2:1**（GB/T 18135 硬要求）。

### 2.6 间距（4 / 8 网格）

| Token | px | 用途 |
|---|---|---|
| `--s-0` | 0 | |
| `--s-1` | 4 | 微间距 |
| `--s-2` | 8 | 行内间距 |
| `--s-3` | 12 | 组件内边距 |
| `--s-4` | 16 | 卡片内边距 |
| `--s-5` | 24 | 区段间距 |
| `--s-6` | 32 | 大区段 |
| `--s-7` | 48 | 页面边距 |

### 2.7 圆角

| Token | px | 用途 |
|---|---|---|
| `--r-0` | 0 | **默认**：卡片、按钮、输入框、Tag、对话框 |
| `--r-1` | 2 | 仅 Tag/SIL 徽章 |

> 工业图纸风核心：**圆角 ≤ 2px**。任何圆角 ≥ 4px 一律视为违反风格。

### 2.8 阴影与模糊

**禁止任何阴影、模糊、发光、渐变（除极淡网格背景外）。**

```css
--shadow-none: none;
```

### 2.9 网格背景（可选暗示）

```css
--grid: rgba(15, 20, 26, 0.04);  /* 8px 方格 */
```

## 3. 组件规则

### 3.1 按钮

- 默认：1.5px 黑边、白底、罗马字 600、字高 13 px、内边距 6×14、**0 圆角**。
- 主操作：黑底白字（不依赖颜色编码，与 ISA 5.1 颜色约定分离，避免误读为关停/动作）。
- 危险：1.5px 红边 + 红字 + 白底（不填充红底，避免与"动作/关停"混淆）。
- 禁用：opacity 0.4 + cursor not-allowed。
- 悬停：边框 1.5px → 2px + 背景 `--paper-2`，**无阴影**。

### 3.2 表格

- **1px 黑色实线**单元格边框（GB/T 18135 表线）。
- 表头：`--paper-3` 底色 + 罗马字 600 + 12 px + 全大写 + 字距 +0.02em。
- 数据行：13 px 罗马字；数字列右对齐 + 等宽罗马字。
- 无 zebra / 无 hover 高亮 / 无圆角。
- 数字字段：等宽罗马字 + tabular-nums。

### 3.3 卡片

- 1.5px 黑色实线边框 + 白底 + **0 圆角**。
- 标题区：12 px 罗马字 + 全大写 + 字距 +0.04em + 下边线 1.5 px 黑色。
- 内容区内边距 16 px。

### 3.4 输入框 / 选择器

- 1px 黑色实线边框 + 白底 + 0 圆角 + 内边距 6×10。
- 聚焦：2px 黑色 outline + offset 0，无 box-shadow。

### 3.5 弹窗（ISO 7200 标题栏风格）

- 遮罩：`rgba(15, 20, 26, 0.55)`（半透明黑，不用模糊）。
- 弹窗：2px 黑色实线边框 + 白底 + 0 圆角。
- 标题区：底部 1.5px 黑色分隔线 + 罗马字全大写 + 字高 13 px。
- 操作区：右上角"取消 / 保存"，黑色实心 + 黑色描边。

### 3.6 状态徽章 / Tag

- **0 圆角**（除 SIL 徽章 2px 微圆角）。
- 内边距 2×8、字高 11 px、罗马字 600。
- 颜色：填充语义色弱底 + 描语义色主线 + 文字描语义色深色（**禁止填充 100% 饱和色**）。

### 3.7 导航（侧栏）

- 背景：墨黑 `#0f141a` + 白字。
- 当前项：左侧 4px 实线 `--acc` + `--paper-2` 底色。
- 文字：罗马字 + 14 px。
- 0 圆角 + 0 阴影。

### 3.8 数字与统计

- 数字：等宽罗马字 + tabular-nums + 字重 700 + 字高 32 px。
- 单位 / 注释：12 px 罗马字 + 全大写 + 字距 +0.04em + `--ink-3`。

### 3.9 图纸标题栏（参考 ISO 7200）

主框架顶栏模仿工程图标题栏：

```
┌────────────────────────────────────────────────────────────────────┐
│ SIF STUDIO              │  PAGE 2 / 7     │  REV B   │  2026-09-13  │
│ 联锁工坊                 │                 │          │  DB v1       │
└────────────────────────────────────────────────────────────────────┘
```

字段（ISO 7200 8 必备字段）：
1. 标题（左侧 `SIF Studio / 联锁工坊`）
2. 创建者（隐）
3. 审核者（隐）
4. 法律所有者（隐）
5. 文档类型
6. 图号 / 文档号（`PAGE n / N`）
7. 页号（同 6）
8. 签发日期（右侧）

## 5. 反模式（禁止清单）

- ❌ 圆角 ≥ 4 px
- ❌ 阴影 / 模糊 / 渐变 / 发光
- ❌ emoji 图标（⚙️ ✅ 等）
- ❌ 圆球进度条 / 弧形进度
- ❌ 居中对称布局（工程图是网格对齐 + 左上原点）
- ❌ 文字斜体（GB/T 14691 禁用）
- ❌ 装饰性背景图
- ❌ 颜色饱和度 > 80%（工程图色板脱饱和）
- ❌ 表格 zebra / hover 高亮
- ❌ font-weight < 400 的辅助文字

## 6. 字体安装说明

**ISOCPEUR / MONOTXT** 在大多数 Windows / macOS 不预装。退路：
- 优先 AutoCAD 自带的 SHX → TTF 转换字体（ISOCPEUR.TTF 在 AutoCAD 安装目录）
- 次选下载 Isonorm 字体（开源，技术制图标准）
- 终极退路：Arial（罗马字）/ Consolas（等宽）

**FangSong_GB2312** 在 Win10/11 已淘汰为 *FangSong*（显示名），老系统可能需要 *FangSong_GB2312.ttf*。

## 7. 验收检查表（每次新页面 / 组件走查）

- [ ] 圆角 ≤ 2 px
- [ ] 边框线宽在 1 / 1.5 / 2 px 中选，相邻 ≥ 2:1
- [ ] 字族在 4 个 token 中选，字高在 7 档中选
- [ ] 数字 / 位号 / 路径 / ID 用 `--font-mono`
- [ ] 标题用 `--font-title`，全大写
- [ ] 颜色只用 token，禁用 hex 魔法值
- [ ] 无 emoji、无渐变、无阴影
- [ ] 表格 1px 黑边、表头全大写、无 zebra
- [ ] 弹窗有 ISO 7200 标题栏区
- [ ] 状态用 ISA 5.1 语义色（红=动作 / 黄=警告 / 绿=验证 / 蓝=信号）
